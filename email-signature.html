  1. In Gmail: Settings (cog) → See all settings → General → Signature.
  2. Create a new signature, click in the box and paste (Cmd+V).
  3. Set it as the default for new emails and replies, then Save Changes at the bottom.
  4. Send yourself a test email and check it on desktop and phone.
